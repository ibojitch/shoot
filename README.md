# ORBIT — 2.5D Shooter

Three.jsで描画する、X/Y平面の横スクロールシューティングMVP。ビルド、npm、画像素材は不要です。

## 起動

Windowsでは`start-server.cmd`をダブルクリックしても起動できます。開いたPowerShellウィンドウはゲーム中そのままにしてください。アプリ外から起動するため、Codex/ChatGPTの検証プロセスの終了に依存せずサーバーを維持できます。

Windowsでは、このフォルダで `powershell -ExecutionPolicy Bypass -File .\start.ps1` を実行し、ブラウザで `http://localhost:8000` を開いてください。PythonまたはCodex同梱のPythonを自動検出します。通常のPython環境では `python -m http.server 8000` でも起動できます。Pythonがない場合は任意の静的HTTPサーバーを使用できます。ES Modulesを使うため、HTMLのダブルクリックではなくHTTPで開きます。

GitHub Pagesでは、このフォルダのファイルをそのまま公開できます。Three.js 0.180.0をjsDelivrから読み込むためインターネット接続が必要です。スマートフォンでも公開URLからプレイできます。

## 操作

- START FLIGHTで開始。WASDまたは矢印キーで移動、Space短押しで通常弾。長押しでチャージし、離すと波動砲。
- スマホは左下のスティックで移動、右下のFIRE短押しで通常弾。長押しして離すと波動砲。横画面推奨。
- P / Escape / 右上ボタンで一時停止。タブを離れると自動停止。
- HPが0になるとGAME OVER。RESTARTでスコア、敵、弾をリセット。

## 実装

HP5、被弾後1.4秒の無敵時間。直進・波状・追尾射撃の3種類の敵。撃破スコアは100 / 150 / 250。時間経過で出現間隔と移動速度が少し上がるエンドレス形式。

ローポリ宇宙船、奥行きから現れる敵、3層の星、回転する遠景構造物、床グリッド、撃破粒子をGeometry / Materialで描画。影とポストプロセスは使用しません。弾・敵・粒子は固定数のプール、GPUのGeometryとMaterialを共有します。衝突はX/Yの円形距離判定。敵の登場中0.7秒は衝突なし。

自機はIBOJITCHの3Dモデルに差し替えています。`playerModel.js`が`ibojitch_player.glb`を読み込み、読み込み完了後にゲームを起動します。テクスチャ画像は使いません。右向き・顔がカメラ側、倍率0.68。モデルの大きさは`playerModel.js`の`root.scale.setScalar()`で調整できます。自機の当たり判定半径0.48と操作・HP・射撃ルールは維持しています。旧宇宙船の噴射エフェクトは削除しました。静的ホスティング時はGLBとローダーも一緒に配置してください。

`game.js`内のGame / Player / Enemy / Bullet / Input / UIクラスで責務を分けています。表示領域は32×18のプレイ範囲を常に収め、縦画面では上下に余白を取ります。床と遠景構造物は背景です。プレイ範囲内を浮遊する岩石には接触ダメージがあります。

## 拡張の入口

- Enemy：敵タイプ、ボス、弾幕。
- Player / Bullet：武器、パワーアップ、シールド。
- Game.update：ステージ進行、地形障害物、アイテム。
- UI：音量設定、ランキング、ステージ選択。

MVPは無音です。実機のスマートフォンにおける60fpsは保証していません。

## 波動砲と岩石

Space / FIREを押すと通常弾を1発発射。200ms以上押して離すと追加で波動砲を発射します。チャージ中は通常弾を連射しません。ゲージは1500msで満タンになり、それ以上長押ししても威力は上限です。一時停止・画面離脱・タッチキャンセルはチャージを破棄します。

威力は通常弾を1として、200msで2、以後100msごとに1増加し、1400msで14。1500ms到達時は最大値の指定を優先し16です。波動砲は弾ごとに残存エネルギーを持ちます。命中対象の残りHPと弾のエネルギーの小さい方だけを消費し、対象を破壊してエネルギーが残れば速度を落とさず貫通します。例：エネルギー16→HP4の敵撃破→残り12。エネルギー0で消滅。弾の大きさ・オーラ・後方の粒子の尾は残量に応じて縮小し、残り1でも波動砲として飛行します。通常弾は従来どおり命中で消滅します。複数の敵や岩石は射線の手前から順に処理し、複数弾は独立計算します。

大岩石はHP16、中岩石はHP8。大岩石が壊れると中岩石2個に分裂し、中岩石が壊れると消滅します。元の速度ベクトルを±30度回転し、速さを保ちます。元が(-50,0)なら(-43.3,±25)。実際のロジック単位は画面サイズに依存しないワールド座標です。分裂時は互いに重ならない位置に配置。接触はプレイヤーHPを1減らし、被弾後の無敵時間が適用されます。岩石の分裂で100点、中の撃破で50点。

`node tests/core.cjs` で戦闘、チャージ境界、分裂と速度、リスタートのロジックを確認できます。

波動砲の尾は`waveTrail.js`の2D Canvasで描画します。残存エネルギーに応じて尾の長さ・幅・粒子数が変化し、スマホでも見える最小サイズを確保します。画像テクスチャや追加の3Dパーツは使いません。`node tests/trail.cjs`で描画位置・縮小・複数弾・リサイズを確認できます。

## うんぽくわっす

通常プレイでは開始8秒後に出現し、撃破後は35秒間隔の出現判定で再登場します。同時に1体まで。デバッグでは `http://127.0.0.1:8000/?debugUnpo=1` を開き、START FLIGHTを押すと即座に出現します。

本体HP256、頭上クリスタルHP16。クリスタルは独立した標的で、保持中・飛行中にショットと波動砲で破壊できます。再生成中は被弾・発射不可。本体を撃破するとクリスタルも除去されます。本体は岩石や他の敵と同じダメージ処理を使い、撃破2000点。接触しても即死せず、プレイヤーに接触ダメージを与えます。

`UnpoEnemy extends Enemy` は本体移動と発射間隔を管理し、`UnpoCrystal extends Bullet` は保持・追尾・等速飛行・消滅・フェード再生成を管理します。頭上の `UnpoSocket` にクリスタルを保持し、発射時はシーンへ移してワールド空間で飛行します。追尾は発射後2秒間のみ旋回速度を制限して補正。その後は速度ベクトルを固定します。プレイヤー・岩石への接触、撃破、画面外のいずれでも消滅し、2秒かけて頭上に再生成します。既存粒子プールから琥珀色の粒子を発生させます。

GLB読み込みは共通の `modelLoader.js` を使い、既存自機にも共用します。セリフはUIクラスの `say()` で表示します。

調整は `unpoConfig.js` の `UNPO_CONFIG`：`homingDuration`（秒）、`homingTurnRate`（rad/s）、`projectileSpeed`（ワールド単位/s）、`regenerationDuration`（秒）、`attackInterval`（秒）。生成処理は `Game.spawnUnpo(x=14,y=0)`。

クリスタルは底面が画面下を向くようZ-upからY-upに補正し、飛行中もその姿勢を保ちます。本体はY軸まわりに約±16度、6秒周期でゆっくり揺れます。調整値は`bodySwayAmplitude`と`bodySwayPeriod`。本体頭上には残りHP / 最大HPとゲージを表示し、撃破後は非表示になります。

本体と帽子は、参考イラストに合わせた丸い白いアヒル、大きな茶色い目、開いた黄色いくちばし、水色の耳当て、琥珀色の渦巻きクリスタルに更新しています。目や頬、羽、耳当ては立体パーツ、帽子の面ごとの色は頂点カラーです。画像テクスチャは不要です。`tools/build_kuwassu.py`で2つのGLBを再生成できます（Python標準ライブラリのみ）。`tools/preview_kuwassu.py`はPillowでモデルの形を確認するオフラインプレビューを作成します。`tests/models.py`でGLBの構造と三角形数を検証できます。

確認手順：デバッグURLで開始し、頭上クリスタルを撃つ→透明から再生成→セリフとともに発射→発射後2秒以上経ってから大きく移動し、弾が追尾を停止していることを確認。発射中もクリスタルを撃つか岩石へ誘導し、再生成されることを確認。一時停止とRESTARTも確認してください。`node tests/core.cjs`にはHP、旋回制限、追尾停止、各消滅理由、フェード、再生成中の発射禁止のテストを含みます。
