# I-JIGEN SHOT — 2.5D Shooter

Three.jsで描画する、X/Y平面の横スクロールシューティングMVP。ビルド、npm、画像素材は不要です。

## 起動

Windowsでは`start-server.cmd`をダブルクリックしても起動できます。開いたPowerShellウィンドウはゲーム中そのままにしてください。アプリ外から起動するため、Codex/ChatGPTの検証プロセスの終了に依存せずサーバーを維持できます。

Windowsでは、このフォルダで `powershell -ExecutionPolicy Bypass -File .\start.ps1` を実行し、ブラウザで `http://localhost:8000` を開いてください。PythonまたはCodex同梱のPythonを自動検出します。通常のPython環境では `python -m http.server 8000` でも起動できます。Pythonがない場合は任意の静的HTTPサーバーを使用できます。ES Modulesを使うため、HTMLのダブルクリックではなくHTTPで開きます。

GitHub Pagesでは、このフォルダのファイルをそのまま公開できます。Three.js 0.180.0をjsDelivrから読み込むためインターネット接続が必要です。スマートフォンでも公開URLからプレイできます。

## 操作

- START FLIGHTで開始。WASDまたは矢印キーで移動、Space短押しで通常弾。長押しでチャージし、離すと波動砲。
- スマホは左下のスティックで移動、右下のFIRE短押しで通常弾。長押しして離すと波動砲。横画面推奨。
- P / Escape / 右上ボタンで一時停止。タブを離れると自動停止。
- HPが0になるとGAME OVER。RESTARTでスコア、敵、弾をリセット。

## 実装

HP5、被弾後1.4秒の無敵時間。直進・波状・追尾射撃の3種類の敵。撃破スコアは100 / 150 / 250。時間経過で出現間隔と移動速度が少し上がるエンドレス形式。

ローポリ宇宙船、奥行きから現れる敵、3層の星、回転する遠景構造物、床グリッド、撃破粒子をGeometry / Materialで描画。影とポストプロセスは使用しません。弾・敵・粒子は固定数のプール、GPUのGeometryとMaterialを共有します。衝突はX/Yの円形距離判定。敵の登場中0.7秒は衝突なし。

自機はIBOJITCHの3Dモデルに差し替えています。`playerModel.js`が`ibojitch_player.glb`を読み込み、読み込み完了後にゲームを起動します。テクスチャ画像は使いません。右向き・顔がカメラ側、倍率0.68。モデルの大きさは`playerModel.js`の`root.scale.setScalar()`で調整できます。自機の当たり判定半径0.48と操作・HP・射撃ルールは維持しています。旧宇宙船の噴射エフェクトは削除しました。静的ホスティング時はGLBとローダーも一緒に配置してください。

`game.js`内のGame / Player / Enemy / Bullet / Input / UIクラスで責務を分けています。表示領域は32×18のプレイ範囲を常に収め、縦画面では上下に余白を取ります。床と遠景構造物は背景です。プレイ範囲内を浮遊する岩石には接触ダメージがあります。

## 拡張の入口

- Enemy：敵タイプ、ボス、弾幕。
- Player / Bullet：武器、パワーアップ、シールド。
- Game.update：ステージ進行、地形障害物、アイテム。
- UI：音量設定、ランキング、ステージ選択。

MVPは無音です。実機のスマートフォンにおける60fpsは保証していません。

## パワーアップ

大岩石の破壊（分裂）時に1/3の確率でアイテムを出し、5種類から等確率で選びます。アイテムは左へ流れ、自機に触れると取得。色付きアイコンはCanvasで生成するため画像ファイルは不要です。装備は画面左上に表示され、RESTARTで初期化されます。

- ピンクのカプセル：エネルギーカプセル。HPを1回復、上限5。
- 水色の3本の弾：ワイドショット。通常弾が2列、再取得で3列。見た目は並行弾ですが、1つの広い当たり判定とダメージ1を共有し、同じ敵への二重ダメージを防ぎます。
- オレンジのロケット：ミサイル。最大2段階。1個取得では右へ1発を2秒ごと、2個取得では上下30°へ2発を1秒ごとに発射します。Shotの短押し・長押しで発射でき、チャージ中も有効。2段階目は自機より上／下の標的をそれぞれ優先し、該当標的がなければ画面全体の最寄りを狙います。威力は各2で、命中すると消滅します。標的は敵・岩石・クリスタル。画面上約100pxの旋回半径をワールド座標に変換。対象が消滅した後は直進し、別の対象へ乗り換えません。
- 緑の稲妻：クイックチャージ。チャージの進行速度は1.5倍（最大チャージは1000ms）ですが、波動砲を発射するには実際の長押し時間が200ms以上必要です。波動砲のエネルギーが+1（最大17）。弾・オーラ・尾・発射と命中の粒子が緑になります。再取得で重複強化はしません。
- 紫の自機と僚機：ウィングポッド。最大2機。自機の過去の移動経路を距離1.3 / 2.6ワールド単位後ろで追い、通常射撃に同期して各1発撃ちます。ポッド自体に当たり判定はなく、波動砲やミサイルは撃ちません。

確認用URL：`http://127.0.0.1:8000/?debugItems=1`。START FLIGHT後、自機の右に5種類を並べます。`&debugUnpo=1`の併用も可能です。

黄色いガードオーブは、クリスタルのHPを0にして破壊したときだけ10%で落ちます。自機で拾うと1個装備し、RESTARTまで有効。追加取得で増えません。自機中心から画面上50pxの円を毎秒2回転し、オーブに触れた赤・茶色の敵弾を消します。オーブは無敵で、雑魚・ボス・クリスタル・岩石に接触開始で1ダメージ、接触が続いている間は50msごとに1ダメージを与えます。高速な円運動は最大1/120秒の区間に分けて衝突判定し、FPSによらず秒数で接触時間を管理します。設定は`game.js`の`ORB_CONFIG`です。

`http://127.0.0.1:8000/?debugOrb=1&debugUnpo=1&debugRage=1`では、START FLIGHT後にオーブを装備し、HP128のボスを即座に出現させます。

## 波動砲と岩石

Space / FIREを押すと通常弾を1発発射。200ms以上押して離すと追加で波動砲を発射します。チャージ中は通常弾を連射しません。ゲージは1500msで満タンになり、それ以上長押ししても威力は上限です。一時停止・画面離脱・タッチキャンセルはチャージを破棄します。

威力は通常弾を1として、200msで2、以後100msごとに1増加し、1400msで14。1500ms到達時は最大値の指定を優先し16です。波動砲は弾ごとに残存エネルギーを持ちます。命中対象の残りHPと弾のエネルギーの小さい方だけを消費し、対象を破壊してエネルギーが残れば速度を落とさず貫通します。例：エネルギー16→HP4の敵撃破→残り12。エネルギー0で消滅。弾の大きさ・オーラ・後方の粒子の尾は残量に応じて縮小し、残り1でも波動砲として飛行します。通常弾は従来どおり命中で消滅します。複数の敵や岩石は射線の手前から順に処理し、複数弾は独立計算します。

大岩石はHP16、中岩石はHP8。大岩石が壊れると中岩石2個に分裂し、中岩石が壊れると消滅します。元の速度ベクトルを±30度回転し、速さを保ちます。元が(-50,0)なら(-43.3,±25)。実際のロジック単位は画面サイズに依存しないワールド座標です。分裂時は互いに重ならない位置に配置。接触はプレイヤーHPを1減らし、被弾後の無敵時間が適用されます。岩石の分裂で100点、中の撃破で50点。

`node tests/core.cjs` で戦闘、チャージ境界、分裂と速度、リスタートのロジックを確認できます。

波動砲の尾は`waveTrail.js`の2D Canvasで描画します。残存エネルギーに応じて尾の長さ・幅・粒子数が変化し、スマホでも見える最小サイズを確保します。画像テクスチャや追加の3Dパーツは使いません。`node tests/trail.cjs`で描画位置・縮小・複数弾・リサイズを確認できます。

## サウンド

スマートフォンではSTART / RESUMEを押した時に全画面表示と横画面固定を試みます（対応ブラウザ）。画面上の「⛶」ボタンでも再試行できます。iPhoneなどで自動切替が使えない場合、縦向きでは横画面の案内を表示し、ゲーム進行・効果演出・音を停止します。端末の回転ロックを解除して横にすると再開します。PCではこの切替を行いません。`node tests/mobileDisplay.cjs`でAPI成功・拒否・非対応・手動回転・再試行を検証できます。

START FLIGHT / RESUMEを押すとWeb Audioで音声が開始します。外部音声ファイルは不要です。BGMは92 BPMのオリジナルのループで、左右に広がる和音、低音、アルペジオ、キック・スネア・ハイハットを重ねます。共有のステレオリバーブとコンプレッサーを使用し、効果音は通常弾、チャージ、波動砲、敵弾、ミサイル、命中、爆発、被弾、アイテム取得、ゲーム終了に対応します。

画面右上の「♪ SOUND」を開き、消音とBGM / SEの音量を個別に調整できます。設定はブラウザに保存します。一時停止・画面離脱中は音声も停止し、RESUMEで再開します。Web Audioが使えない環境でもゲームは続行できます。スマートフォンではブラウザや端末の消音設定も確認してください。

`sound.js`の`SOUND_CONFIG`でBPM、リバーブ時間、初期音量、最大同時発音数を調整できます。`scheduleBeat()`がBGM、`effect()`が効果音、`setCharge()`がチャージ音です。ノイズとリバーブ素材は初回のみ生成し、発音後は音声ノードを切断します。`node tests/sound.cjs`で開始操作、発音数制限、チャージ終了、消音、一時停止と再開、ゲーム終了を検証します。

最大チャージを保持すると、チャージ音に約4.8Hz・±24Hzのビブラートが滑らかに加わります。最大前は従来の上昇音です。`chargeVibratoRate`と`chargeVibratoDepth`で揺れる速さ・幅を調整できます。発射・キャンセル・一時停止時にはビブラートも停止します。

チャージ音は約73.3Hz→440Hzを基本とし、少し音程をずらした鋸歯状波2本と1オクターブ下の低音を重ねます。軽いソフト歪みとチャージに合わせて開くフィルターで、野太いエネルギーの唸りを表現します。`chargeDrive`（歪み）と`chargeUnisonDetune`（重ねる音のずれ、cent）で調整できます。

確認手順：再読み込み→START→短押し射撃→長押しして波動砲→アイテム取得・敵撃破・被弾→SOUNDの音量調整と消音→一時停止とRESUME→GAME OVERとRESTART。

敵を撃破すると、赤・オレンジの火球、黄色の閃光、飛び散る火花を表示します。撃破音は中高音の破裂音と低い衝撃音を重ね、通常の命中音と区別します。くわっす撃破時は大きな初期爆発と5回の連続爆発、約2秒の轟音を再生します。爆発は128個の共有粒子プールを使い、一時停止中は進行せず、RESTARTで残りの連続爆発を消去します。

## うんぽくわっす

通常プレイでは開始8秒後に出現します。撃破するとステージ1クリアとなり、ステージ2へ移行します。デバッグでは `http://127.0.0.1:8000/?debugUnpo=1` を開き、START FLIGHTを押すと即座に出現します。

本体HP256、頭上クリスタルHP16。クリスタルは独立した標的で、保持中・飛行中にショットと波動砲で破壊できます。再生成中は被弾・発射不可。本体を撃破するとクリスタルも除去されます。本体は岩石や他の敵と同じダメージ処理を使い、撃破2000点。接触しても即死せず、プレイヤーに接触ダメージを与えます。

`UnpoEnemy extends Enemy` は本体移動と発射間隔を管理し、`UnpoCrystal extends Bullet` は保持・追尾・等速飛行・消滅・フェード再生成を管理します。頭上の `UnpoSocket` にクリスタルを保持し、発射時はシーンへ移してワールド空間で飛行します。追尾は発射後2秒間のみ旋回速度を制限して補正。その後は速度ベクトルを固定します。プレイヤー・岩石への接触、撃破、画面外のいずれでも消滅し、2秒かけて頭上に再生成します。既存粒子プールから琥珀色の粒子を発生させます。

GLB読み込みは共通の `modelLoader.js` を使い、既存自機にも共用します。セリフはUIクラスの `say()` で表示します。

調整は `unpoConfig.js` の `UNPO_CONFIG`：`homingDuration`（秒）、`homingTurnRate`（初期rad/s）、`homingEasePower`（旋回の減衰指数、初期値2）、`projectileSpeed`（ワールド単位/s）、`regenerationDuration`（秒）、`attackInterval`（秒）。追尾中の旋回速度は時間とともに減衰し、旋回半径が徐々に広がって2秒時点で直進に移ります。生成処理は `Game.spawnUnpo(x=14,y=0)`。

自機の誘導ミサイルは共有Geometryによる8角形の胴体・円錐の先端・尾翼で構成します。後方の橙色と明るい芯の噴射炎は、進行方向に追従し、小さく伸縮します。既存のミサイルプールを使用し、毎フレームのモデル生成はありません。

ウンポク・ワッスはHP128以下になると、次の発射から左正面・上下22.5°・上下45°の5方向へクリスタルを射出します。弾速は6→9、誘導時間は2→3秒。各弾のHPは16で独立して破壊できます。頭上の再生成は1個のまま、発射時に4個の追加弾を既存クリスタル処理で飛ばします。追加弾が飛行中の場合は次の5方向発射を待ちます。設定値は`rageHp`、`rageShotCount`、`rageSpeedMultiplier`、`rageHomingMultiplier`、`rageSpreadAngle`です。

誘導中の同じボスのクリスタル同士には、近づいたときだけ弱い斥力が働きます。5発では10組の距離比較で計算し、旋回速度制限を通して離れる方向へ補正。誘導終了時は斥力も停止します。調整は`separationDistance`（初期値1.7ワールド単位）と`separationStrength`（初期値1.0、旧0.85から約18%増加）です。

飛行中の各クリスタルは1秒ごとに20%の確率で、自機へ茶色い通常敵弾を発射します。速度8・被弾ダメージ1で、雑魚の敵弾とプールを共用。保持・再生成中は発射しません。波動弾は赤・茶色の通常敵弾を撃ち落とし、1発につき残存エネルギーを1消費します。敵・岩石・敵弾への衝突を命中順に処理し、エネルギーが0になったら波動弾も消滅。通常弾・ミサイルは通常敵弾を撃ち落としません（ステージ2の敵誘導ミサイルは撃ち落とせます）。設定は`unpoConfig.js`の`bulletRollInterval`、`bulletFireChance`、`bulletSpeed`、`orbDropChance`です。

クリスタルは底面が画面下を向くようZ-upからY-upに補正し、飛行中もその姿勢を保ちます。本体はY軸まわりに約±16度、6秒周期でゆっくり揺れます。調整値は`bodySwayAmplitude`と`bodySwayPeriod`。本体頭上には残りHP / 最大HPとゲージを表示し、撃破後は非表示になります。

クリスタルの再生成中はY軸まわりに3回転し、高速から滑らかに減速して、実体化完了時に元の向きで完全停止します。発射後は4秒で1回転の速さでY軸まわりに回転します。破壊・プレイヤーや岩石への接触・画面外・本体撃破による消滅時には、その場に茶色い粒子を出します。再生成位置には移動させず、RESTART時には発生させません。調整箇所は`unpoConfig.js`の`regenerationSpinTurns`、`projectileSpinRate`、`crystalParticleColor`です。

クリスタルは先端のカーブを保ち、下側に半周を追加した約2.5巻きの見た目です。588三角形の大きな面、半透明（不透明度0.78）、低い粗さで琥珀の結晶感を出します。再生成のフェードは素材の透明度に掛け合わせます。表面の頂点を初回のみ記録し、保持・再生成・飛行中に小さな明るい茶色の粒子を少量発生させます。`crystalSparkleColor`と`crystalSparkleInterval`で調整できます。

本体と帽子は、参考イラストに合わせた丸い白いアヒル、大きな茶色い目、開いた黄色いくちばし、水色の耳当て、琥珀色の渦巻きクリスタルに更新しています。目や頬、羽、耳当ては立体パーツ、帽子の面ごとの色は頂点カラーです。画像テクスチャは不要です。`tools/build_kuwassu.py`で2つのGLBを再生成できます（Python標準ライブラリのみ）。`tools/preview_kuwassu.py`はPillowでモデルの形を確認するオフラインプレビューを作成します。`tests/models.py`でGLBの構造と三角形数を検証できます。

確認手順：デバッグURLで開始し、頭上クリスタルを撃つ→透明から再生成→セリフとともに発射→発射後2秒以上経ってから大きく移動し、弾が追尾を停止していることを確認。発射中もクリスタルを撃つか岩石へ誘導し、再生成されることを確認。一時停止とRESTARTも確認してください。`node tests/core.cjs`にはHP、旋回制限、追尾停止、各消滅理由、フェード、再生成中の発射禁止のテストを含みます。


## ステージ2

ステージ1のウンポク・ワッス撃破で新規出現を止めます。4秒後に自機を無敵化し、1.25秒で自機・ウィングポッド・ガードオーブ以外を黒へフェードアウト。ステージ2を準備し、1.25秒でフェードインして通常プレイへ戻ります。HP・スコア・装備・位置・僚機の軌跡を引き継ぎます。P/ESCによる一時停止やスマホの縦画面待機中は移行タイマーも停止します。RESTARTはステージ1からです。

`stage2Data.js`に64区間の通路と9基の砲台配置を保持します。`tools/generate_stage2.py`で再生成でき、通路の最小幅、隣接区間の接続、プレイヤーの移動速度で到達可能な経路を検査します。プレイ中に地形をランダム生成しません。`terrain.js`は描画、円を膨張した矩形による移動経路の衝突判定、自機の通路内への補正を担当します。地形に触れると通常の接触ダメージと無敵時間が発生。通常弾・自機ミサイル・波動弾・敵弾・飛行クリスタルは地形で消滅します。

`Turret extends Enemy`は地形に固定され、スクロールに追従します。本体HP4、撃破200点、2.4秒間隔で発射。弾は既存の`Missile extends Bullet`を共用し、HP1・ダメージ1・速度6（自機ミサイルの半分）、旋回半径は自機と同じ画面上100pxです。通常弾・ミサイル・波動弾・オーブで撃ち落とせます。波動弾の消費エネルギーは1。

約67秒で広いボス区間へ入り、`BattleshipEnemy extends UnpoEnemy`が登場します。低ポリゴンの装甲・艦橋・エンジン・噴射炎と2基の甲板砲台を持ち、既存のクリスタル攻撃を再利用します。艦橋のウンポク・ワッスが弱点でHP512、撃破5000点。船体には装甲付きの当たり判定があります。撃破後の移行演出でMISSION CLEARを表示します。

調整値：`game.js`の`STAGE_CONFIG`（移行待ち時間、フェード時間、砲台HP・発射間隔、戦艦HP、敵ミサイル速度）、`stage2Data.js`の`scrollSpeed`・`bossDistance`・`sections`・`turrets`。戦艦形状は`battleshipModel.js`で変更できます。

確認用URL（開いてSTART FLIGHT）：

- `http://127.0.0.1:8000/?debugStage2=1`：ステージ2の先頭。
- `http://127.0.0.1:8000/?debugBattleship=1`：戦艦戦へ直接移動。
- `http://127.0.0.1:8000/?debugTransition=1`：HP1のステージ1ボス。Spaceで倒し、4秒待機→フェード→SECTOR 02への移行を確認。

`node tests/core.cjs`に地形の接続、移動経路上の遮断、敵ミサイルの撃ち落とし、移行時間・無敵化・引き継ぎ・再開始の検査を追加しています。


ウィングポッドの通常弾は、自機より上にあるポッドから前方斜め上10°、同じ高さまたは下にあるポッドから前方斜め下10°へ発射します。弾速24・ダメージ1は従来通り。角度は`game.js`の`POD_SHOT_ANGLE`で調整できます。

`?debugInvincible=1`を付けると、自機HPが減らないデバッグモードになります。敵弾・敵本体・岩・地形の被弾に共通して有効で、RESTARTやステージ移行後も維持します。地形の通路内への補正は有効です。装備表示に`INVINCIBLE`が表示されます。ほかのオプションとは`&`で連結できます。例：`http://127.0.0.1:8000/?debugStage2=1&debugItems=1&debugOrb=1&debugInvincible=1`。オプション名は大文字・小文字を区別します。


### 地形・装甲・戦艦波動砲の更新

地形は隣接区間の高さを共有する斜面に変更し、三角形の岩盤メッシュと面ごとの陰影で凹凸を表現します。衝突判定も同じ斜面の輪郭を使います。既存の色、保存済みのステージデータ、通路の接続は維持します。

ステージ2の通常敵は3ワールド単位先の通路まで調べ、上下の目標位置と速度を滑らかに変更して回避します。波打ち・追尾の個性は通路内で残します。位置を直接補正するのは壁に触れる直前の緊急時だけです。

砲台は撃破時に1/3の確率で既存5種類のアイテムから等確率でドロップします。地形砲台と甲板砲台の両方が対象。アイテムは通路内の位置へ出現させます。

船体・甲板・艦橋に輪郭による当たり判定を追加しました。接触すると自機へダメージを与えます。船体の装甲への攻撃は`Math.floor(攻撃力/2)`だけ共通HPにダメージを与えます。通常弾は0、ミサイルは1、エネルギー16の波動弾は8。装甲が弾を吸収するため、残存エネルギーは0となり、波動弾も消滅します。くわっす本体は引き続き装甲なしの弱点です。

戦艦は艦首へ粒子を集めて2秒チャージし、左へ太い波動弾を発射します。チャージの後半1秒は戦艦の上下位置を固定して射線を予告します。発射後7秒待機して再チャージ。被弾はHP-1、地形で消滅、自機の波動砲・オーブでは消去できません。HPゲージの名称欄でもチャージ・発射を表示します。既存の弾処理と粒子プールを共用し、新しい粒子システムは追加していません。`STAGE_CONFIG.shipChargeTime`・`shipWaveInterval`・`shipWaveSpeed`で調整できます。

`debugBattleship=1&debugWave=1`を併用すると、艦首チャージの終盤からボス戦を開始し、波動砲をすぐ確認できます。


## コンティニューと余剰アイテム

ゲームタイトルは`I-JIGEN SHOT`、コピーライトは`©BOJIGEN`です。タイトル・ゲームオーバー画面でSキーを押すと新規開始／RESTART。ゲームオーバー画面でCキーまたはCONTINUEボタンを押すと、その場・そのステージから再開します。HPは5へ回復し、2秒間無敵。スコアだけを0へリセットし、ワイド段階・ミサイル段階・クイックチャージ・ウィングポッド・オーブをすべて維持します。ステージ進行・敵とボスの残りHPも維持し、画面上の敵弾は消去します。プレイ中のSキーは従来通り下移動です。

HP最大でのエネルギーカプセル、上限到達済みのワイド／ミサイル／ポッド、取得済みのクイックチャージ／オーブなど、装備・HPが変わらない取得時は自機の後方へ黄色いフォグを出します。柔らかな描画にはコードで生成した放射状グラデーションを使い、画像ファイルは不要です。フォグは背景スクロール速度（ステージ1は2.5、ステージ2は3ワールド単位/秒）で左へ流れ、1.5秒でフェードアウトします。最初の1秒だけ敵とクリスタルに対するダメージ判定を持ち、接触中は0.1秒ごとに1ダメージ。岩・地形・敵弾は対象外です。一時停止中はフォグの時間も停止し、再開始・ステージ移行で消去します。`game.js`の`FOG_CONFIG`で寿命・ダメージ期間・間隔・範囲を調整できます。

## ビジュアル・サウンドの改善（2026-10-08）

`scenery.js`で宇宙の星雲・惑星・光の裂け目、ステージ2の装甲パネル・配管・冷却光を描画します。背景と地形表面のテクスチャは初期化時にCanvasで生成し、再利用します。地形はUV・材質・輪郭の飾りだけを追加し、形状・当たり判定・ステージ配置は変更しません。背景生成は専用の疑似乱数を使用します。キャラクターの3Dモデルは変更していません。

タイトルはシステムフォントとCSSによる金属調のロゴです。ボスの名前とHPバーは画面上部に固定し、名前をバーの上に分離しています。攻撃状態とHP数値の更新処理は保持し、通常はCSSで非表示にします。URLに `debugHud=1` を付けると再表示します。例：`?debugBattleship=1&debugHud=1&debugInvincible=1`。

BGMは宇宙（100 BPM）・要塞（116 BPM）・ボス（136 BPM）の3種類に切り替わります。`sound.js`の`THEMES`で和音・テンポ・音色を調整できます。装甲命中と弱点命中の効果音を分け、波動砲・ボス登場・ボス撃破ではBGMを一時的に下げます。MISSION CLEARには専用の短いファンファーレがあります。音量・消音・一時停止の機能は引き継ぎます。

今回追加した図形・テクスチャ・楽曲パターンはコードで独自に作成しています。第三者の画像・音源・フォントファイルの追加やダウンロードはありません。既存のThree.jsなどの依存関係は従来どおりです。

検証：既存の `tests/core.cjs`・`tests/sound.cjs`・`tests/trail.cjs`・`tests/mobileDisplay.cjs` に加え、`node tests/presentation.cjs` でChromeの描画、PC／横画面サイズ、タッチ表示、ボス情報の通常／デバッグ表示、音楽切り替え、一時停止と再開を確認します。このブラウザテストにはChromeとPlaywrightが必要です（ゲーム本体の依存には追加していません）。必要に応じて `NODE_PATH` でPlaywrightのインストール先を指定してください。

## ミサイルの地形追従

自機のミサイルは進行方向の滑らかな床・天井を先読みし、敵への追尾より地形回避を優先して旋回します。地形に沿う間も速度12・威力2・元の標的ロックを維持し、地形から離れれば元の標的への追尾に戻ります。標的消滅後も地形回避は有効です。地形回避中だけ旋回半径を最大1.5ワールド単位に縮め、座標を地形の外へ強制移動する処理は使いません。

垂直な面、接続していない段差、斜面の角度差が90°以上の折れ目には追従しません。実際に衝突した時点で爆発します。敵や岩への命中では従来のダメージ処理後に爆発して消滅し、爆風による追加ダメージはありません。地形と敵の接触順序は移動区間の衝突時刻で決まります。敵側ミサイル・通常弾・波動砲の地形挙動は変更していません。

`node tests/core.cjs` で床・天井・左右方向・標的消失・急な段差・衝突順序、および30/60/120fpsでの地形追従とスクロールを検証します。


## ステージ1の動きと敵編隊

宇宙背景の星雲・惑星・光の裂け目は約2秒で1画面px左へ流れます。近景に当たり判定のない漂流物を追加しました。誘導タイプは自機の高さへ接近し、編隊タイプはHP1の3機で高速接近、各機1発の狙い弾を撃って右へ離脱します。編隊と誘導タイプはステージ1に出現します。長い終了画面タイトルも表示幅に合わせて縮小します。
